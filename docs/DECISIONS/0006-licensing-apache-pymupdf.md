# ADR 0006: Apache-2.0 license; PyMuPDF caveat

Status: accepted (2026-11-11)

## Context and decision
Project is Apache-2.0. PyMuPDF (AGPL-3.0 or commercial) is a required dependency for PDF extraction.

## Consequences
Local use is fine; redistribution/service use triggers AGPL duties. Follow-up: replace with a permissive parser or make it optional. Unresolved.
